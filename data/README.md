# Data

The dataset is **not included** in this repository. It was provided to participants of the MIT Applied AI & Data Science Program.

To run the notebook locally, place the zip file here:

```
data/
└── Facial_emotion_images.zip
```

The notebook extracts it to `data/Facial_emotion_images/` with this layout:

```
Facial_emotion_images/
├── train/       {happy, neutral, sad, surprise}/   15,109 images
├── validation/  {happy, neutral, sad, surprise}/    4,977 images
└── test/        {happy, neutral, sad, surprise}/      128 images
```

All images are 48×48 grayscale JPEGs.
